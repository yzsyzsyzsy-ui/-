# Level up! Integrated V3

COMPLETE V1과 Awakening V2를 하나로 합친 전체 통합본입니다.

## 기존 프로젝트에서 유지·복원된 기능
- 이름 입력, 레벨, 경험치와 레벨 트로피
- 오전 2시 기준 일일 퀘스트
- 기상·취침 인증
- 러닝 사진 업로드, OCR 날짜·시간·거리 분석, 직접 수정, 중복 방지
- 등·이두 / 가슴·어깨·삼두 / 하체·복근 운동 루틴
- 4회마다 운동 단계 상승, 10단계, 짝수 단계 훈장
- 날짜별 뇌내혁명 일기
- 우선순위·진행률 목표와 달성 목표 진열
- 구매 예정, 수정, 구매 완료, 되돌리기, 지출 총액
- 사랑·인생 마도서 100권씩
- 사용자가 작성하는 나의 배움
- 사랑하는 사람 기록 메인퀘스트
- 금연 기록과 기간별 보상
- 진열장과 데이터 백업·복원

## 새 게임 시스템
- 최초 시작 시 B급 각성자
- 일일 퀘스트 전체 완료 시 EXP 10 + 10 coin
- 금연은 서브퀘스트로 분리
- 1~5단계 던전, 보스·쫄병, 승리·패배 모션
- 각 던전 최초 클리어 시 각성도전권 1개
- B→A 100%, A→A+ 80%, A+→S 75%, S→S+ 70%
- 재능의 숲 1~4단계
- 보컬·복싱·피부관리 파밍 조건
- 12개 장비, 가방, 장착 슬롯
- 공격·마력·스피드·방어를 생활 능력치에 환산
- coin 시스템 상점과 전투 포션·강화석
- 마도서 최초 해제 비용 1 coin, 지식·정신력 각 0.5 상승

## GitHub 업로드
ZIP 자체를 올리지 말고 압축을 해제하세요. 폴더 안의 모든 파일과 assets 폴더를 저장소 최상단에 업로드해야 합니다.

필수 파일:
- index.html
- app.js
- styles.css
- game-data.json
- workout-plans.json
- content.json
- manifest.json
- sw.js
- icon.svg
- .nojekyll
- assets 폴더 전체

저장소 첫 화면에 index.html이 바로 보여야 합니다.

GitHub Pages:
Settings → Pages → Deploy from a branch → main → /(root)

기존 캐시를 피하려면 새 저장소를 사용하거나 주소 뒤에 `?integrated=3`을 붙이세요.
